# Machine Learning Projects Collection

This repository contains three machine learning projects implemented using Python and Jupyter Notebook. These projects demonstrate the application of data preprocessing, model training, evaluation, and prediction using different datasets and machine learning techniques.

## 📂 Projects Included

### 1. Handwritten Character Recognition
A deep learning project that recognizes handwritten digits using the MNIST dataset.

#### Features
- Uses Convolutional Neural Networks (CNN)
- Trained on the MNIST handwritten digit dataset
- Image preprocessing and normalization
- Model training and evaluation
- Handwritten digit prediction

#### Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib

---

### 2. Credit Scoring Model
A machine learning model that predicts credit risk based on customer financial information.

#### Features
- Data preprocessing and cleaning
- Handling categorical variables using Label Encoding
- Exploratory Data Analysis (EDA)
- Credit risk classification
- Model evaluation and performance analysis

#### Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

---

### 3. Disease Prediction from Medical Data
A machine learning project that predicts the likelihood of a disease based on patient medical information.

#### Features
- Medical data preprocessing
- Exploratory Data Analysis (EDA)
- Feature selection and preparation
- Disease prediction using machine learning algorithms
- Model evaluation and accuracy assessment

#### Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

---

## 🛠 Requirements

Install the required libraries before running the notebooks:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn tensorflow
```

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/your-repository-name.git
```

2. Navigate to the project directory:

```bash
cd your-repository-name
```

3. Open Jupyter Notebook:

```bash
jupyter notebook
```

4. Open any notebook and run all cells.
